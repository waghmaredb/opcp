# Security policy

## Reporting a vulnerability

Please report security issues privately to **hello@twomuchlabs.com**, not in a public issue.

Include what you found, how to reproduce it, and the version or commit affected. We will acknowledge your report and keep you informed as we investigate and fix it, and we will credit you in the release notes unless you prefer otherwise.

## Scope

- The OPCP reference runtime and command-line tools in this repository.
- The Exit-Readiness Scorecard, its offline form and generated reports, including anything that could cause assessment data to leave the user's machine.
- The schemas and specification, where a flaw could lead implementations to behave unsafely.

## Supported versions

OPCP is a draft for comment. Fixes are made on the latest version on the `main` branch.
